# preflight — 종료 전 한 번

한 번 훑고, 걸리는 것을 한 번에 고친다. 세 번째 패스는 없다. 하나라도 정직하게 체크 못 하면 끝난 게 아니다.

## 기계적 (세거나 grep 가능)
- [ ] 원색(hex/rgb/oklch) 0개 — tokens.css 밖. `font-family` 직접 지정 0개. (훅이 확인하지만 Bash로 쓴 파일은 못 본다)
- [ ] 그라데이션 0개 (스켈레톤 시머 토큰 제외). AI-purple 0개.
- [ ] Tailwind 기본 팔레트 클래스(`bg-blue-500` 등) 0개.
- [ ] 아이브로우(`uppercase` + `tracking`) 0개. 섹션 번호 라벨 0개.
- [ ] 그림자 쓴 요소 ≤ 3개. 그림자 값은 토큰 3단계 중 하나.
- [ ] 라디우스 값은 `control | card | sheet | full` 중 하나만. 임의 px 없음.
- [ ] 이모지·유니코드 글리프를 아이콘으로 쓴 곳 0개. 아이콘 라이브러리 1종.
- [ ] `h-screen`/`100vh` 0개 (→ `dvh`). `transition: all` 0개. `z-[999]`류 임의 z-index 0개. bounce/elastic 이징 0개.
- [ ] `word-break: break-all` 0개. `tracking-tighter` 0개 (한글).
- [ ] em-dash(—) 0개 — 화면에 보이는 텍스트.
- [ ] primary CTA 화면당 1개. 같은 의도의 버튼 중복 0개.
- [ ] `<html lang="ko">`.

## 판단 (눈으로)
- [ ] 상태 5종: hover · disabled · loading(스켈레톤) · error · empty.
- [ ] 대비: 본문 4.5:1, 큰 글자·아이콘·포커스 3:1. 버튼 텍스트가 배경 위에서 읽힌다. 폼 플레이스홀더·헬퍼·에러 텍스트도.
- [ ] 액센트 1색이 페이지 전체에서 같은 역할로 쓰인다. 7번째 섹션에서 갑자기 다른 색 CTA 없음.
- [ ] 한 화면 안에서 라이트/다크 섹션 섞이지 않음. 다크모드에서 한 번 확인.
- [ ] 터치 타겟 ≥ 44px, 사이 간격 ≥ 8px. 키보드로 전부 도달 가능, 포커스 링 보임.
- [ ] `prefers-reduced-motion`에서 깨지지 않음.
- [ ] 375 / 768 / 1280에서 가로 스크롤 없음, 고정 내비 뒤에 가려진 콘텐츠 없음.
- [ ] 실제 카피. 로렘 입숨·홍길동·`99.9%`·"차세대"·"혁신적인" 없음. 성공 메시지에 느낌표 없음. 에러는 문제 + 복구.
- [ ] 화면에 보이는 모든 문자열을 한 번 다시 읽었다. 어색한 문장은 평범한 문장으로 바꿨다.
- [ ] 모든 애니메이션에 한 문장 이유가 있다. 없으면 뺐다.
- [ ] 카드는 계층이 필요한 곳에만. 중첩 카드 없음.
- [ ] 브리프의 모든 요구가 있고 몇 초 안에 찾을 수 있다.

## 런타임 감사 (선택, 정규식이 못 보는 것)

정적 룰은 명도 대비·가로 오버플로·터치타겟·`focus-visible`처럼 "렌더링해야 아는" 결함을 못 본다. dev 서버가 떠 있으면 마지막에 한 번 돌린다(playwright 필요, 없으면 건너뜀):

```bash
node .claude/hooks/design-audit.mjs http://localhost:5173
```

blocker(대비 미달·오버플로·lang/viewport 누락)는 고친다. warn(터치타겟·포커스·이름·alt)은 검토한다.
