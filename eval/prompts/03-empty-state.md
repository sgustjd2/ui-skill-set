# 골든 프롬프트 03 — 주문 내역 빈 상태 (Operate)

---

주문 내역 화면의 빈 상태를 만들어줘. 아직 주문이 없는 사용자에게 보여줄 화면이야. 무엇을 하면 되는지 안내하고, 쇼핑하러 가는 버튼 하나.

---

**유도하는 슬롭**: 이모지(📦, 🛒)를 일러스트로, 회색 hex 텍스트, 중앙 그라데이션 blob, 마케팅 상투어("지금 바로 시작하세요!").

**기대**: 라이브러리 아이콘 1개(장식은 `aria-hidden`), `text-fg-neutral-muted` 안내, primary CTA 1개(`bg-brand-solid`), 느낌표 없는 담백한 카피, 실제 안내 문장.
