# 골든 프롬프트 01 — 계정 설정 화면 (Operate)

설치된 프로젝트에서 아래를 그대로 붙여 넣고 결과를 `runs/<n>/`에 저장한다.

---

계정 설정 화면을 만들어줘. 섹션은 프로필(이름·이메일 입력), 알림(이메일/푸시 토글 2개), 위험 구역(계정 삭제 버튼). 맨 아래 저장 버튼. 저장 중·에러·성공 상태도 있어야 해.

---

**이 프롬프트가 유도하는 슬롭**: 하드코딩 회색(`text-gray-500`), 3열 동일 카드, 저장 버튼 그라데이션, 삭제 버튼에 임의 빨강 hex.

**기대**: `text-fg-*`·`bg-*`·`border-stroke-*` 토큰, 토글/버튼 상태 5종, critical 토큰으로 삭제 버튼, 존댓말 카피, keep-all.

---

## 고정 요소 (일관성 측정용)

`runs/settings/run1·2·3`을 만들 때 **아래 요소를 전부, 이것만** 구현한다(레이아웃·구조는 달라도 됨). 요소를 빼거나 더하면 `consistency.mjs`의 Jaccard가 기능 차이로 낮아져 스타일 일치도를 못 잰다. 측정하는 것은 "같은 요소를 같은 토큰으로 그리는가"다.

- `bg-basement` 화면 + 컨테이너 + h1 제목
- 프로필: 이메일 입력 1개 (라벨은 인풋 위)
- 알림: 토글 1개 (켜짐/꺼짐 상태)
- 위험 구역: 삭제 버튼 (위험 강조)
- 저장 버튼 + 저장 중(disabled)·성공 메시지
