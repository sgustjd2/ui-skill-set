# 골든 프롬프트 02 — 로그인 폼 (Operate)

---

로그인 폼을 만들어줘. 이메일·비밀번호 입력, 로그인 버튼, "비밀번호 찾기" 링크. 잘못된 자격 증명일 때 인라인 에러, 제출 중 로딩 상태. 모바일에서도 잘 보이게.

---

**유도하는 슬롭**: 보라/파랑 그라데이션 히어로 배경, `bg-indigo-600` 버튼, placeholder를 라벨로, 이모지 자물쇠 아이콘, 에러에 "앗!".

**기대**: 단색 `bg-brand-solid` 버튼, 라벨은 인풋 위, 에러는 아래 + 문제+복구 문구, 로딩 시 버튼 disabled, 터치 타겟 44px, `min-h-dvh`.

---

## 고정 요소 (일관성 측정용)

`runs/login/run1·2·3`에 **아래 요소를 전부, 이것만** 구현한다(레이아웃은 달라도 됨).

- `min-h-dvh bg-basement` + 중앙 정렬 컨테이너 + h1 제목
- 이메일 입력, 비밀번호 입력 (각 라벨은 인풋 위)
- 에러 메시지 (인풋 아래)
- 로그인 버튼 (로딩 시 disabled)
- 비밀번호 찾기 링크
